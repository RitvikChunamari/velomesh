# Prompt Architect

Transform ambiguous or terse prompts into actionable full-stack specifications while preserving 100% of the user's stated intent.

## Workflow
1. Inspect the raw prompt for three pillars: **Domain & Target Users**, **Core Workflows & Data Flows**, and **Aesthetic Direction & Technical Stack**.
2. If core product vision decisions are missing, ask 2–3 high-leverage clarifying questions via `brainstorming` / `grilling` rather than guessing generic SaaS defaults.
3. Attach matched **already-installed platform skills** across Antigravity, Codex, Claude Code, Cursor, OpenCode, and Copilot alongside curated internet capabilities.
4. Append concrete engineering invariants:
   - Frontend: typography scale (`>=12px` functional floor), WCAG AA contrast, `prefers-reduced-motion`, zero AI-slop templates.
   - Backend & Database: parameterized queries, row-level security / tenant scoping, idempotent webhooks, structured errors.
   - Verification: automated unit tests + rendered desktop/mobile check.
