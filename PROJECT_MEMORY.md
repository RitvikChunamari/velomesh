# VeloMesh Project Memory (`PROJECT_MEMORY.md`)

## Project Purpose & Architecture
- **VeloMesh** (`v4.2`) is an open-source, autonomous Multi-Model & Full-Stack Engine for AI coding agents (`Claude Code`, `Cursor`, `OpenAI Codex`, `GitHub Copilot`, `Google Antigravity`, and `OpenCode`).
- It operates automatically via `<!-- VELOMESH:START -->` rules, `PreInvocation` hooks (`scripts/hooks.mjs`), the `/velomesh` core skill (`SKILL.md`), and the persistent loopback gateway (`127.0.0.1:4190`), coordinating **Dynamic Multi-Model Switching (`velomesh/auto`) + Awwwards-grade Frontend UI + GSAP/WebGL Motion + Backend APIs + PostgreSQL/Prisma Schemas + Live Internet MCP/API Provisioning + Autonomous TDD & Browser QA**.
- **Vision Elaboration Principle:** VeloMesh automates 100% of the *engineering stack, skills, MCP servers, APIs, and subagents*, but **cannot get inside the user's brain to see their product vision**. Underspecified prompts are flagged by `assessVisionClarity()` / `recommend_fullstack_bundle()` (`NEEDS_ELABORATION`) to trigger `brainstorming` / `grilling` clarifying questions before generating code; vision-elaborated prompts (`READY_FOR_FULLSTACK_EXECUTION`) execute end-to-end in one shot.
