# VeloMesh Project Memory (`PROJECT_MEMORY.md`)

## Project Purpose & Architecture
- **VeloMesh** (`v4.3`) is an open-source, autonomous Multi-Model, Platform Skill, Prompt Optimizer, & Hooks Super-Tool for AI coding agents (`Claude Code`, `Cursor`, `OpenAI Codex`, `GitHub Copilot`, `Google Antigravity`, and `OpenCode`).
- It operates automatically via `<!-- VELOMESH:START -->` rules, universal hooks (`scripts/hooks.mjs`: `invocation`, `prompt-submit`, `pre-tool`, `post-tool`, `status`), the `/velomesh` core skill (`SKILL.md`), and the persistent loopback gateway (`127.0.0.1:4190`), coordinating **Platform-Native Skill + Internet Mesh Unification, Automatic Prompt Optimization (`scripts/prompt-optimizer.mjs` + `optimize_prompt`), RTK + Popular Hooks Suite, Dynamic Platform-Native Model Switching (`velomesh/auto`), Awwwards-grade Frontend UI, GSAP/WebGL Motion, Backend APIs, PostgreSQL/RLS Schemas, & Browser QA**.
- **Vision Elaboration Principle:** VeloMesh automates 100% of the *engineering stack, skills, MCP servers, APIs, and subagents*, but **cannot get inside the user's brain to see their product vision**. Underspecified prompts are flagged by `assessVisionClarity()` / `recommend_fullstack_bundle()` (`NEEDS_ELABORATION`) to trigger `brainstorming` / `grilling` clarifying questions before generating code; vision-elaborated prompts (`READY_FOR_FULLSTACK_EXECUTION`) execute end-to-end in one shot.
